# ROADMAP & Progress Tracker (Universal WebDAV & Network Drive Service)

Документ отслеживания этапов разработки универсального C# WebDAV-сервиса и сетевого диска Telegram.

Архивная дорожная карта версии V1 (AIMP Plugin) сохранена в файле: [`ROADMAP_V1_AIMP_PLUGIN.md`](./ROADMAP_V1_AIMP_PLUGIN.md).

---

## 📌 Текущий статус проекта
- **Фаза**: Реализованы все модули C# сервиса: база данных SQLite WAL, WebDAV сервер, WTelegramClient с защитой FLOOD_WAIT, парсер тегов ATL.NET, TrayContext и форма настроек WinForms.
- **Целевая платформа**: Windows Desktop / C# (.NET 8.0/9.0) Tray App & Background Service.
- **Протокол**: WebDAV (`http://localhost:{port}/`, настраиваемый порт) + Автомонтирование сетевого диска (`Z:`, `T:`, `Y:`, `W:` или авто-выбор).

---

- [x] Создание таблицы трекинга незавершенных загрузок `upload_progress` (ID файла, позиция сбойного чанка, хеш) для докачки при обрывах.
- [x] Проектирование связей версионирования для файлов и структуры виртуальной корзины (`.Trash`).

- [x] Включение режима WAL для SQLite (`PRAGMA journal_mode=WAL;`) для безопасного конкурентного доступа.

### [x] Этап 2: Универсальный C# WebDAV Сервер
- [x] Создание легкого фонового HTTP/WebDAV сервера на C# (порт `37000`).
- [x] Создание структуры обработки запросов (OPTIONS, PROPFIND, GET, PUT, MKCOL, DELETE, MOVE).
- [x] Реализация XML-ответов `PROPFIND` с привязкой к SQLite.
- [x] Реализация записи, версионирования и управления: `PUT`, `MKCOL`, `DELETE`, `MOVE`.
- [x] Логика обработки перезаписи файлов: сохранение прежней версии как `v1` в корзину и присвоение текущему файлу версии `v2`.
- [x] Виртуальное отображение папки корзины (`Z:\.Trash` / `Z:\Корзина`) и механизм восстановления предыдущих версий.
- [x] Реализация заголовков `Accept-Ranges: bytes` и статуса `206 Partial Content` для быстрой перемотки и докачки файлов на ПК.

### [x] Этап 3: Интеграция с WTelegramClient & Авторизация
- [x] Разработка каркаса `TelegramService` для подключения, управления сессией (`.session`) и многошаговой авторизации.
- [x] Встроенный интерфейс входа в Telegram (ввод номера телефона, получение SMS/Telegram кода, ввод 2FA-пароля).
- [x] Управление файлом сессии `.session` и отслеживание статуса подключения (Подключено / Требуется вход).
- [x] Реализация двухнаправленного потока с поддержкой докачки:
  - Стриминг при чтении из Telegram (`Client.DownloadFileAsync`) по Range-запросам (`offset` + `count`).
  - Надежная загрузка чанков в Telegram (`Client.UploadFileAsync`) с возможностью возобновления оборванных загрузок (Resumable Uploads) по прогрессу из `base.db`.
  - Поддержка заголовка `Content-Range` в запросах `PUT` со статусом `202 Accepted` для умного софта резервного копирования (Rclone, GoodSync, FreeFileSync).
  - Автоматическая очистка временных записей из `upload_progress` при успешном завершении загрузки файла.
- [x] Отработка паузы потока при получении `FLOOD_WAIT` от Telegram без разрыва соединения с Проводником.
- [x] Буферизация памяти с помощью `ArrayPool<byte>`.
