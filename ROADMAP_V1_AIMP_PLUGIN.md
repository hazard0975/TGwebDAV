# ROADMAP & Progress Tracker

Документ отслеживания этапов разработки, запланированных задач и выполненного прогресса.

---

## 📌 Текущий статус проекта
- **Фаза**: Проектирование и обсуждение архитектуры.
- **Выбранная технология**: C# Native AOT / C++ Wrapper DLL для AIMP с внутренним WebDAV-сервером (`WTelegramClient` + SQLite `base.db`).

---

## 📋 Этапы разработки

### [ ] Этап 1: Проектирование схемы базы данных (`base.db`)
- [ ] Добавить колонки/таблицу для аудио-тегов (`artist`, `title`, `album`, `year`, `genre`, `track_number`, `duration_seconds`, `bitrate`).
- [ ] Добавить хранение идентификаторов обложек (`cover_telegram_file_id` или `cover_blob`).
- [ ] Добавить колонку для кэширования заголовочных байт файла (`header_cache_bytes`).
- [ ] Включить режим WAL для SQLite (`PRAGMA journal_mode=WAL;`).

### [ ] Этап 2: C# WebDAV & HTTP Сервер
- [ ] Создать легкий встроенный HTTP/WebDAV слушатель на C#.
- [ ] Реализовать поддержку WebDAV методов (`PROPFIND`, `GET`, `HEAD`, `OPTIONS`).
- [ ] Реализовать правильные HTTP-заголовки `Accept-Ranges: bytes` и статус ответа `206 Partial Content`.

### [ ] Этап 3: Интеграция с Telegram (`WTelegramClient`)
- [ ] Реализовать потоковую передачу данных из Telegram (`Client.DownloadFileAsync`) по Range-запросам (`offset` + `count`).
- [ ] Добавить кольцевой буфер в памяти (`ArrayPool<byte>`) для сглаживания сетевых задержек.
- [ ] Реализовать предзагрузку (prefetching) следующего фрагмента аудио.

### [ ] Этап 4: Автоматическое чтение и кэширование тегов
- [ ] Подключить библиотеку `ATL.NET` для быстрой работы с аудио-тегами через `Stream`.
- [ ] Реализовать извлечение тегов при первом сканировании / загрузке трека и сохранение в `base.db`.

### [ ] Этап 5: Сборка AIMP Plugin DLL
- [ ] Создать обертку экспорта функции `AIMPPluginGetHeader` для загрузки плагина AIMP.
- [ ] Настроить автозапуск WebDAV-сервера при старте AIMP и остановку при выходе.

### [ ] Этап 6: Тестирование и интеграция
- [ ] Подключение в AIMP: «Мои облака» -> «Custom (WebDAV)».
- [ ] Тестирование воспроизведения, перемотки (Seek), отображения обложек и работы с плейлистами.
- [ ] Проверка параллельного доступа при работе плагина Total Commander.
